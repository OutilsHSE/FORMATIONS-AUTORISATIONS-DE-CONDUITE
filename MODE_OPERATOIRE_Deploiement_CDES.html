Ce que vous allez déployer

Le dispositif repose sur trois briques. Les applications tournent dans le navigateur du collaborateur ; aucune donnée n'est stockée sur son poste — tout remonte dans un Google Sheet qui vous appartient.

Les applications
Fichiers HTML publiés en ligne. Le référent les ouvre sur PC, tablette ou téléphone.

⚙️

📊

3 onglets : Fiches, Autorisations, Journal. Votre tableau de bord.

5 min

3.2 — Le carnet d'adresses des signataires Recommandé

💬
D'abord, à quoi servent les // ? En informatique, deux barres obliques en début de ligne signifient « ceci est une note pour l'humain, l'application doit l'ignorer ». On appelle cela mettre en commentaire. Dans le fichier livré, les deux lignes d'exemple sont volontairement mises en commentaire pour que l'application démarre sans adresse. Retirer les //, c'est activer la ligne.

Cherchez AC_SIGNATAIRE_MAILS dans le fichier (Ctrl + F). Vous trouverez ceci — les deux lignes grisées commencent par //, elles ne servent donc à rien pour l'instant :

// ❌ ÉTAT LIVRÉ — les lignes d'exemple sont inactives
const AC_SIGNATAIRE_MAILS = {
  // "Prénom NOM - Directeur Général": "a.momeux@cdes.fr",
  // "Prénom NOM - Responsable HSE": "prenom.nom@cdes.eu",
};

Remplacez ce bloc par vos vraies adresses, sans les //, une ligne par personne :

// ✅ ÉTAT ATTENDU — les lignes sont actives
const AC_SIGNATAIRE_MAILS = {
  "Prénom NOM - Directeur Général": "a.momeux@cdes.fr",
  "Prénom NOM - Directeur Général": "m.audebert@cdes.fr",
  "Prénom NOM - Responsable d'Agence": "t.petit@cdes.fr",
  "Prénom NOM - Responsable Exploitation": "m.bomble@cdes.fr",
  "Prénom NOM - Responsable HSE": "prenom.nom@cdes.eu",
};

La règle de lecture est simple : à gauche le nom tel qu'il apparaît dans le menu déroulant, deux points, à droite son adresse, et une virgule en fin de ligne. Vous pouvez en mettre 3, 5 ou les 12 — seuls ceux que vous renseignez seront reconnus.

3.3 — Comment le formulaire utilise ce carnet

Dans la page Autorisation, deux champs travaillent ensemble :

ChampRôle
Responsable signataire
Menu déroulant		Le nom imprimé sur la carte, dans le bloc « Pour le Responsable ». Toujours les 12 personnes de la liste CDES.
Email du responsable
Champ libre		L'adresse qui recevra le mail de demande de signature. Se remplit toute seule si le responsable choisi figure dans le carnet — sinon vous la tapez à la main.

Autrement dit : oui, vous choisissez le destinataire à chaque autorisation. Le carnet ne fait que vous éviter de retaper les adresses les plus fréquentes. Un message sous le champ vous indique en permanence où vous en êtes :

Message affichéSignification
✉️ Adresse enregistrée pour ce responsableElle vient du carnet, rien à faire.
✏️ Adresse saisie manuellementVous l'avez tapée ou modifiée pour cet envoi.
⚠️ Aucune adresse enregistréeCe responsable n'est pas dans le carnet : saisissez son adresse.
🛡️
Si vous changez de responsable en cours de saisie, le champ email est vidé automatiquement quand le nouveau n'a pas d'adresse au carnet. Impossible d'envoyer par inadvertance l'autorisation à la personne précédemment sélectionnée.
💾
Enregistrez les fichiers en UTF-8. Sous Bloc-notes : Fichier → Enregistrer sous → Encodage : UTF-8. Sans quoi les accents s'afficheront en caractères bizarres.

4.2 — Comment les noms de fichiers deviennent des adresses

Le principe est direct : chaque fichier déposé garde son nom et devient accessible à sa propre adresse. Il n'y a rien à déclarer, rien à configurer — poser le fichier suffit.

Fichier déposé dans le dépôtAdresse publique correspondante
fiche_faucardage_cdes.html…github.io/cdes-hse/fiche_faucardage_cdes.html
autorisation_conduite_cdes.html…github.io/cdes-hse/autorisation_conduite_cdes.html
fiche_manitou_cdes.html…github.io/cdes-hse/fiche_manitou_cdes.html
🏠
Le cas particulier de index.html. Un seul nom a un statut spécial : index.html. C'est le fichier servi quand on ouvre l'adresse du dépôt sans préciser de fichier. Autrement dit, …github.io/cdes-hse/ affiche automatiquement index.html. Il n'est pas obligatoire — sans lui, cette adresse renvoie une erreur 404, mais chaque fiche reste accessible à son adresse complète. C'est simplement la page d'accueil de votre portail.

C'est pour cela que je vous livre un index.html : une page d'accueil aux couleurs CDES qui liste les fiches en ligne, celles à venir, l'autorisation de conduite et vos ressources (registre, Vigiminute, ce mode opératoire). Avec dix fiches à terme, vous ne diffusez qu'une seule adresse aux équipes au lieu d'onze.

✏️
Règles de nommage à respecter pour tous les fichiers : pas d'accents, pas d'espaces (utilisez des tirets ou des soulignés), et attention à la casse — sur GitHub Pages, Fiche.html et fiche.html sont deux fichiers différents. Le nom que vous donnez apparaîtra dans l'adresse : choisissez-le lisible, il sera cliqué par les référents.

Phase 5 — Mise en service

Mode opératoire — le référent chantier

À transmettre aux référents. Tient en cinq lignes.

#ActionPoint de vigilance
1Ouvrir le lien de la fiche. Si la formation a déjà commencé, retaper prénom + nom dans « Reprendre une fiche existante ».Toujours la même orthographe du nom, sinon une seconde fiche est créée.
2Renseigner le collaborateur, le référent, les dates, puis le check-up HSE et les équipements sur le schéma.Un équipement non coché déclenche un report au service HSE.
3Dérouler les pages Sécurité et Savoir : présenter les consignes par thème, puis cliquer sur Vu, Compris ou Maîtrisé.L'onglet Validation reste verrouillé tant que le Savoir-Faire n'est pas entamé.
4Page Validation : commentaires et trois signatures au doigt ou à la souris.Les 3 signatures font passer la fiche en Terminée.
5Page Autorisation : générer, puis Envoyer au responsable pour signature.L'enregistrement est automatique — inutile de cliquer sur Enregistrer à chaque champ.
📶
Sur un chantier sans réseau : la fiche fonctionne normalement, seul l'enregistrement échoue (badge orange). Utilisez 📁 Export JSON pour conserver une trace, et réenregistrez une fois le réseau revenu. Rien n'est perdu tant que l'onglet reste ouvert.

Mode opératoire — le responsable signataire

Rien à installer, rien à apprendre : il reçoit un mail et clique.

#Ce qu'il fait
1Il reçoit le mail « ✍️ Autorisation de conduite à signer — Nom Prénom » et clique sur le lien.
2L'autorisation s'affiche seule, en lecture seule — il ne peut rien modifier.
3Il signe dans le cadre « Pour le Responsable » : au doigt sur téléphone ou tablette, à la souris ou au stylet sur PC. Ou il imprime la carte pour la signer à la main.
4Il clique sur ✅ Valider et signer — le bouton reste grisé tant qu'il n'a pas signé.
5Il peut télécharger son exemplaire PDF. De votre côté, vous recevez le mail de confirmation et le statut passe à Signée.

Phase 6 — Créer une nouvelle fiche

~5 min par activité

Pour les neuf activités restantes. Ni le Sheet ni le script ne sont à retoucher : le registre est commun et distingue les activités par leur ficheId.

CléÀ renseigner
ficheIdIdentifiant unique, sans espace ni accent : "pelle-amphibie". C'est lui qui sépare les activités dans le registre.
activiteLe grand titre du bandeau : "PELLE AMPHIBIE".
sousTitreLa précision sous le titre : "Conduite d'une pelle amphibie".
machineNom et description de l'engin, affichés en tête du volet Savoir.
epiLes équipements. side (L/R) et top placent l'étiquette, ax/ay le point d'ancrage de la flèche sur le personnage — le tout en % du cadre.
savoirThemesLes consignes regroupées par thème, chacune avec son type : interdit, obligation, vigilance ou info.
savoirFairePhasesLe parcours pratique, découpé en phases dans l'ordre réel de la formation.
autorisationligneDefaut : garder la formulation type « Conduite d'une pelle amphibie sur la base d'une formation au poste de travail ». Plus perimetre, poste, signataire.
apiUrlLa même URL que la fiche faucardage.
🤝
Le plus simple reste de m'envoyer la fiche Word de la prochaine activité : je vous rends le fichier configuré, prêt à publier.

Dépannage

SymptômeCause probable et correctif
Badge orange « Hors ligne (URL non configurée) »apiUrl est resté vide dans le fichier. Reprenez le point 3.1.
« Échec enregistrement »Trois causes, dans l'ordre : l'URL ne se termine pas par /exec ; le déploiement n'est pas réglé sur Qui a accès : Tout le monde ; le script a été modifié sans être redéployé en nouvelle version.
« Aucune fiche trouvée » alors qu'elle existeL'orthographe du prénom ou du nom diffère de la saisie initiale. Vérifiez la colonne cle de l'onglet Fiches — c'est elle qui sert de clé de recherche (accents et majuscules sont ignorés, pas les fautes de frappe).
Aucun mail ne partREPORT_EMAIL est vide ; ou les autorisations n'ont pas été acceptées au déploiement. Ouvrez l'éditeur Apps Script, lancez une fois la fonction doGet à la main et acceptez les accès.
Le lien de signature ne s'ouvre pasLes fichiers n'ont pas été publiés en ligne (phase 3), ou le lien a été généré depuis un fichier local. Régénérez-le depuis l'adresse GitHub Pages.
Le responsable voit une page videL'autorisation n'avait pas été enregistrée avant l'envoi. Rouvrez la fiche, cliquez sur Générer puis renvoyez le lien.
Le PDF sort en noir et blancActivez Graphismes d'arrière-plan dans « Plus de paramètres » de la boîte d'impression.
L'autorisation sort sur 2 pagesLes marges d'impression ont été forcées. Remettez-les sur Par défaut et l'échelle sur 100 % : le format paysage est piloté par le document.
Accents remplacés par des symbolesLe fichier a été réenregistré dans un autre encodage. Réenregistrez-le en UTF-8.
Une fiche en double dans le registreDeux orthographes du même nom. Reprenez la bonne ligne et supprimez l'autre — la fiche la plus complète est celle au plus fort pourcentage.
🔎
Pour diagnostiquer côté serveur : dans l'éditeur Apps Script, menu Exécutions — vous y voyez chaque appel reçu, avec les erreurs éventuelles.

Annexes

Les trois onglets du registre

OngletContenu
FichesUne ligne par fiche de formation : identifiant d'activité, clé, nom, prénom, statut (En cours / Terminée), progression %, date de mise à jour, anomalies en cours, et le contenu intégral au format JSON — signatures comprises. C'est la source de vérité pour la réouverture.
AutorisationsUne ligne par autorisation de conduite, qu'elle soit vierge ou issue d'une fiche : date, source, activité, titulaire, poste, aptitude médicale, restrictions, liste des autorisations, options PE/TEL, date de validité, périmètre, signataire, email, statut (En cours / Envoyée pour signature / Signée), date de signature et lien. Votre tableau de bord des titres en attente.
JournalUne ligne par enregistrement : date et heure, activité, collaborateur, référent, avancement, statut, anomalies. Le fil chronologique complet, utile en cas de contrôle ou d'audit.
